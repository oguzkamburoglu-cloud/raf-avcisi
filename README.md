# Raf Avcısı (mobil uygulama)

PickyList'in oyunu Raf Avcısı, Capacitor ile Android ve iOS uygulaması olarak.

```
npm install
npm run sync      # src/ → www/ → android/ ve ios/
npm run android   # Android Studio
npm run ios       # Xcode
```

Mağazaya yükleme adımları: [MAGAZA_REHBERI.md](MAGAZA_REHBERI.md). Mağaza metinleri: [store/MAGAZA_METINLERI.md](store/MAGAZA_METINLERI.md).
